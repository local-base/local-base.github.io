Privacy Policy

Last updated: October 15, 2026

Purpose

This application is used exclusively by its owner to back up and synchronize personal files with Google Drive using rclone.

Data Access

The application accesses Google Drive files as authorized by the owner. File data is processed for backup and synchronization purposes only.

Data Sharing

The application does not sell or share Google Drive data with third parties.

Authentication

Authentication is performed using Google OAuth. OAuth credentials are stored locally and are not published on this website.

Data Retention

Backup data is retained according to the owner's backup configuration. The owner can delete stored backup data.
